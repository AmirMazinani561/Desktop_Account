مبنای این پوشه: **`DATA_MODEL.md` نسخه ۰.۲** (تأییدشدهٔ کارفرما) و **`PRD.md` نسخه ۰.۳**.

> ⚠️ این پوشه فعلاً **قابل‌حمل (portable)** است: تا وقتی «استراتژی کد» (ردیف ۵ جدول تصمیم‌های PRD)
> قطعی شود، همین‌جا می‌ماند و بعد از تصمیم، عیناً به ریشهٔ اپلیکیشن منتقل می‌شود
> (`db/prisma/` ← `prisma/` و `db/sql/` ← `prisma/sql/` یا `db/migrations/`).

## تقسیم مسئولیت (مهم)

| مسئولیت | کجا | چرا |
|---|---|---|
| جدول‌ها، ستون‌ها، انواع، کلیدهای خارجی، ایندکس‌های ساده، یونیک کامل | `schema.prisma` | Prisma این‌ها را تولید و نسخه‌بندی می‌کند |
| قیدهای `CHECK` شرطی و چندستونی | `sql/0001_...` | Prisma از `CHECK` پشتیبانی نمی‌کند |
| ایندکس یونیک **partial** (`WHERE ...`) و **functional** (`lower(name)`, `COALESCE(...)`) | `sql/0001_...` | در Prisma بیان‌شدنی نیست |
| تریگرها (تضمین تراز، تغییرناپذیری سند، قفل دوره، درخت حساب، `email_lower`) | `sql/0001_...` | منطق سطح دیتابیس؛ PRD آن را **اجباری** می‌داند |
| توابع سرویس (`fn_next_serial`, `fn_apply_balance_delta`, `fn_rebuild_period_balances`) | `sql/0001_...` | باید اتمیک و داخل همان تراکنش اجرا شوند |
| viewها (`v_simple_transactions`, `v_account_ledger`, `v_trial_balance`, `v_unbalanced_journals`) | `sql/0001_...` | Prisma view را به‌عنوان مدل نمی‌شناسد |
| RLS (امنیت چندمجموعه‌ای) | **فاز ۳** (مهاجرت جدا) | طبق `DATA_MODEL.md` بند ۸ |

## ترتیب اجرا (اولین بار)

```bash
npm install ; npx prisma migrate dev --name phase0_init ; psql "$DATABASE_URL" -v ON_ERROR_STOP=1 -f db/sql/0001_core_constraints_and_triggers.sql ; npx prisma db pull --print | head -40
```

نکته‌ها:
1. `ON_ERROR_STOP=1` **الزامی** است؛ بدون آن خطای یک قید می‌تواند بی‌صدا رد شود.
2. فایل SQL عمداً **idempotent نیست** (`ADD CONSTRAINT` تکراری خطا می‌دهد) تا «نیمه‌اجرا شده» نماند.
   اگر نیاز به اجرای مجدد بود، اول با `DROP CONSTRAINT IF EXISTS` پاک کنید.
3. پس از اجرا، `prisma db pull --print` را با `schema.prisma` مقایسه کنید؛ تفاوت‌های معنادار = نشانهٔ drift.
4. در CI این مراحل روی Postgres واقعی اجرا می‌شوند و سپس **تست‌های طلایی** موتور مالی
   (سناریوهای `DATA_MODEL.md` بخش ۱۰) پاس می‌شوند.

## قراردادهایی که در کد باید رعایت شوند

1. **ثبت سند همیشه در یک تراکنش:** ساخت `DRAFT` ← افزودن آرتیکل‌ها ← گرفتن شماره با `fn_next_serial` ← `UPDATE status='POSTED'`.
   اگر هر قدم شکست، کل تراکنش رول‌بک می‌شود (و شماره هم برمی‌گردد → بی‌شکاف).
2. **`total_debit`/`total_credit`/`line_count` را دستی ننویسید** — تریگر `trg_journal_lines_recompute` آن‌ها را نگه می‌دارد.
3. **سند ثبت‌شده را UPDATE نکنید** — تریگر رد می‌کند. اصلاح = سند معکوس (`reverse_of_journal_id`) + سند جدید.
4. **`accounts.path` و `depth` را دستی ننویسید** — تریگر `trg_accounts_tree` می‌سازد.
5. **`email_lower` را دستی ننویسید** — تریگر `trg_users_email_lower` از `email` مشتق می‌کند.
6. **`app.company_id` را در هر تراکنش دیتابیس ست کنید** (`SET LOCAL app.company_id = ...`)؛
   از فاز ۳ که RLS فعال شود، این تنها لایهٔ تفکیک دادهٔ مجموعه‌ها در سطح دیتابیس است.
7. **مبالغ فقط `BigInt` و فقط مثبت**؛ علامت از `side` و طبیعت حساب مشتق می‌شود.
8. **تاریخ شمسی:** `date` میلادیِ مدنی منبع حقیقت است و `jalali_*` با تابع قطعیِ مشترک
   (`lib/jalali.ts` — هنوز ساخته نشده) پر می‌شود. دو پیاده‌سازی متفاوتِ تبدیل = باگ مانده‌ها.

## وضعیت اعتبارسنجی در محیط فعلی

| بررسی | ابزار | نتیجه |
|---|---|---|
| ساختار `schema.prisma` (سازگاری دوطرفهٔ ۱۰۴ رابطه، وجود ستون‌های ایندکس/یونیک، تعریف‌شدن همهٔ enumها، غیرoptional بودن کلید اصلی) | پارسر `@mrleebo/prisma-ast` + اسکریپت بررسی سفارشی | ✅ پاس (۲۰ مدل، ۲۹ enum) |
| نحوِ کل فایل SQL | **پارسر واقعی PostgreSQL** (`libpg-query` نسخه ۱۷) | ✅ پاس (۵۷ جمله: ۱۳ تابع، ۱۱ `ALTER TABLE`، ۹ ایندکس، ۹ تریگر، ۴ view، ۲ بلوک `DO`) |
| جمله‌های SQL داخل بدنهٔ توابع | استخراج + پارسر واقعی PostgreSQL | ✅ پاس (۶ جمله) |
| اجرای واقعی تریگرها روی Postgres | — | ❌ در این سندباکس ممکن نیست (Postgres/Docker و `binaries.prisma.sh` در دسترس نیستند) → **باید در CI اجرا شود** |

> طبق `Agents.md`: چون Postgres در سندباکس نیست، تست سرتاسری ممکن نیست.
> جایگزین فعلی = اعتبارسنجی سطح پارسر + تست توابع خالص؛ تست واقعی تریگرها و
> تست‌های طلایی/رد (negative) در CI با Postgres موقت انجام می‌شود.
